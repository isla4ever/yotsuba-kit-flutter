# Yotsuba Schedule v1.0.0

首个可直接安装体验的 Android 应用版本。无需 Flutter、Android Studio 或项目源码，下载 APK 后即可运行完整的课表与 Today 应用。

## 下载

- `Yotsuba-Schedule-Android-1.0.0.apk`：适用于 Android 7.0 及以上设备的通用安装包。
- `Yotsuba-Schedule-Android-1.0.0.apk.sha256`：安装包完整性校验文件。

首次从浏览器或文件管理器安装时，Android 可能要求确认“允许此来源安装应用”。这是系统对非应用商店 APK 的正常保护流程。

## 主要能力

- 课表、Today 与设置三个主要模块
- 单双周、非本周、重叠课程、节假日与调休补班
- 多种换周动画、课程信息密度、主题和天气背景
- 课程详情、教材与携带物、课程任务和日程计划
- 本地离线数据、JSON 导入导出、ICS 与系统日历同步
- 定位天气与按课程时段渲染的天气效果

## 安全与兼容性

- APK 使用 Yotsuba Schedule 项目专属密钥签名，支持后续版本覆盖升级。
- 课程与计划默认保存在设备本地；定位和日历权限仅在相应功能使用时请求。
- 本次 Release 仅提供 Android 安装包，不包含无法直接安装的未签名 iOS 文件。
