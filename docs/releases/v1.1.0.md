# Yotsuba Schedule v1.1.0

本版对 Flutter 完整应用进行了一轮移动端重构，让课表、Today、设置和课程详情与 Yotsuba Web 演示保持一致的产品语义和交互节奏。

## 下载

- `Yotsuba-Schedule-Android-1.1.0.apk`：适用于 Android 7.0 及以上设备的通用签名安装包。
- `Yotsuba-Schedule-Android-1.1.0.apk.sha256`：安装包完整性校验文件。

## 主要更新

- 课程卡改为六套真实可切换的鲜明调色板，不再使用固定的阴沉色值。
- 天气材质与课程底色有机融合；非本周课程仍保持失色，不会被天气重新染色。
- 课表 Header、周次区、工具栏与 Dock 向 Web 演示对齐，保留移动端信息密度。
- Today 重构为九种可编辑模块，`1x1 / 1x2 / 2x1 / 2x2` 分别使用独立排版，320px 屏幕下也不挤压。
- 设置改为可调整位置的毛玻璃弹层，不再打断当前课表或 Today 上下文。
- 课程详情在标题区融合分时天气、温度、教材与课程任务。
- 修复周切换时重叠课程和天气卡短暂闪现的问题，PC 鼠标拖动也可模拟移动端换周手势。
- 更换全新应用图标，以课表为主体，四叶草与天气元素作为辅助修饰。

## 验证范围

- Flutter 静态分析与完整应用测试。
- `yotsuba_schedule_kit` 组件包静态分析与全部测试。
- 320px / 390px 移动端视口的课表、Today、设置和课程详情截图验收。
- 课程点击、鼠标拖动换周、配色切换和弹层开关交互。

## 安全与兼容性

- APK 使用 Yotsuba Schedule 项目专属密钥签名，可直接覆盖升级 v1.0.0。
- 课程、任务和设置默认保存在设备本地；定位与日历权限仅在对应功能使用时请求。
- 本次 Release 仅提供 Android 安装包。
